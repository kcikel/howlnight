# Howlnight

Mobile-first PWA narrator for in-person Werewolf / Mafia (4–20 players, one phone).

## Stack

Vite + TypeScript + Preact · Vite PWA · Vitest · Web Speech API

## Commands

```bash
npm install
npm run dev
npm test
npm run simulate
npm run build
npm run preview
```

## Local path

`/workspace/howlnight`

Built assets: `/workspace/howlnight/dist`
